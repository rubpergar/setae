# Security

Setae is a local Windows utility. The application does not record, transcribe, upload, or persist microphone audio, and the current MVP does not make network requests during normal execution.

## Reporting a vulnerability

Please do not include microphone recordings, personal settings, or other private data in a public issue. Use GitHub's private vulnerability reporting for this repository when available. If it is not available, contact the maintainer through the GitHub profile before publishing details.

Useful information includes:

- Setae version or commit.
- Windows version and architecture.
- Reproduction steps.
- A minimal error message or redacted log, if one exists.

Do not run untrusted builds with administrator privileges. Official release artifacts should be checked against the SHA-256 file published with the release.
